24 层各自干什么

Publisher

制造事件

把外部信号包成 Event 子类塞给 bus。不只是 window，timer / asset / network 都能发。

EventBus

路由派送

维护 byType + byCategory 两份订阅表，fan-out 给所有命中者；handled 时短路。

Layer

订阅入口

每个 layer 暴露 onEvent(event: Event)。收到通用 Event，内部用 dispatcher 拆。

Dispatcher

类型匹配

dispatch(ctor, fn)：是这种类型就调 fn，TS 自动缩窄；fn 返回 true 标 handled。

3handled 怎么截断的

bus 在 publish 的时候按顺序触发匹配到的 handler，任何一个把 event.handled 设为 true，bus 就立刻 return，不再继续推给剩下的订阅者。

  1. 1 bus.publish(keyPressedEvent) · 找到 byType.get(KeyPressed) 里的三个 handler 集合。
  2. 2 遍历 byType：调用 InputLayer.handler → 它内部 dispatcher 命中 → 调 fn → fn 返回 true → event.handled = true。
  3. 3 bus 看到 handled === true，跳出 type 循环。
  4. 4 byCategory 那一轮 不再执行。DebugLayer 这次就看不到这次按键了。
  5. 5 如果 fn 返回 false：handled 保持 false，bus 继续推给下一个 subscriber。

设计意图：UI layer 通常应该"消费掉"自己的事件，避免被调试层 / 日志层重复处理。但 logging 这种横切关注点，handler 必须返回 false，否则系统会"丢事件"。

4Layer 同时是订阅者和发布者

上图的 publisher 框里没画 layer，但这是事件系统能 scale 的关键 —— layer 可以处理完事件后再 emit 新事件，bus 完全不区分 source。

作为 Subscriber

收 bus 推来的 event

在 onEvent 里用 dispatcher 拆类型 → 命中后跑业务逻辑。InputLayer 听到 KeyPressedEvent，把按键状态写进自己的 model。

作为 Publisher

处理完 emit 新 event

同样是这个 InputLayer，可以在状态变更后 bus.publish(new InputStateChangedEvent(...))。下游的 UI / Analytics layer 订阅新事件即可。

这就是为什么我们前面说 bus 是事件汇聚的中转站，不是 window 专属管道。publisher / subscriber 是相对概念，每跳一次 hop 都是一次 publish。

5Layer 端的标准 dispatch 写法

这是 packages/engine/src/events/dispatcher.ts 的实际用法模板，将来 layer 系统落地时直接照搬：

class MyLayer {
  onEvent(event: Event): void {
    const dispatcher = new EventDispatcher(event)

    dispatcher.dispatch(KeyPressedEvent, (e) => {
      console.log('key', e.keyCode, 'repeat', e.repeatCount)
      return true   // 消费掉，bus 后续不再分发
    })

    dispatcher.dispatch(WindowResizeEvent, (e) => {
      this.relayout(e.width, e.height)
      return false  // 不消费，让 debug / network layer 也能看到
    })

    dispatcher.dispatch(MouseButtonPressedEvent, (e) => {
      this.handleClick(e.button)
      return true
    })
  }
}

三个 dispatch 调用彼此独立 —— 第一个返回 true 不会让后面两个跳过，因为 dispatcher 检查的是 event instanceof ctor，不是 event.handled。这种"全部试一遍"的语义让 layer 写起来很线性。
